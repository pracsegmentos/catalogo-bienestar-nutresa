Conectar con GitHub

Para guardar cambios necesitas un token personal de GitHub con acceso de escritura solo a este repositorio.

  1. Entra a github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Crea uno nuevo, dale acceso solo al repositorio catalogo-bienestar-nutresa.
  3. En permisos, activa Contents: Read and write.
  4. Copia el token generado y pégalo aquí abajo.

El token se guarda solo en este navegador (nunca se sube al repositorio).
